# Проект VR-арены

Python-прототип находится в `vr_arena/`, тесты — в `tests/`, демонстрация — `demo.py`. Данные хранятся в памяти.

Запуск из корня: `python demo.py`, `python run_cases.py`, `python -m unittest discover -v`. Требуется Python 3.10+. При изменении кода выполнять оба набора проверок. Сохранять согласованность алгоритмов, документа и тестов. Коммиты делать тематическими, по аналогии с существующей историей. Не перезаписывать чужие изменения.

Рабочая копия после этапа 3: `docs/report/Ульянкин_ВИ_ИКБО-30-24_Учебная_практика_этап4_этап3_готово.docx`. Схемы BPMN упрощены с согласия пользователя. В разделе 3.3 описаны Java-реализация и фактическая проверка; сравнение подходов относится к этапу 4.

После этапа 3 реализация Java находится в `java/`. Команды из этого каталога: `mvn -q test`, затем `java '-Dfile.encoding=UTF-8' '-Dstdout.encoding=UTF-8' -cp target/classes ru.mirea.vrarena.Demo`. Используется Java 17 (`maven.compiler.release=17`), JUnit 5; состояние хранится в памяти. Сопоставлять реализацию с рисунком 16 и таблицами 15–16.
