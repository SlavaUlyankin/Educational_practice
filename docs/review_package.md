## Что проверять

1. `java/src/main/java/ru/mirea/vrarena/BookingService.java` — проверка слота, перенос, отмена, неявка и фиксация истории. Обратить внимание на границы времени, изоляцию площадок и отсутствие изменений после отказа.
2. `SessionService.java` — переходы состояния и расчёт оставшегося времени и превышения.
3. `EquipmentService.java` — допустимые переходы, выдача, неисправность, замена и предварительная проверка возврата.
4. `Booking.java`, `BookingHistory.java`, `Arena.java` и `SessionEquipment.java` — данные и связи, достаточность ограничений и согласованность с сервисами.
5. `java/src/test/java/ru/mirea/vrarena/ArenaServicesTest.java` и `Demo.java` — проверяемые случаи и воспроизводимость результатов. При желании сопоставить алгоритмы с Python-модулями `vr_arena/a1_slots.py`, `a2_session_time.py`, `a3_equipment.py`, `a4_bookings.py`.

Данные хранятся в памяти, одновременная запись несколькими администраторами, платежи и база данных не реализованы. Java дополнительно проверяет активность и вместимость площадки; Python-прототип этого не делает. Это границы текущего результата, которые можно обсудить в рецензии.

## Как проверить

Нужны JDK 17 и Maven либо IntelliJ IDEA со встроенным Maven. Подробная инструкция — `java/README.md`. Из каталога `java`:

```powershell
mvn -q test
java '-Dfile.encoding=UTF-8' '-Dstdout.encoding=UTF-8' -cp target/classes ru.mirea.vrarena.Demo
```

При первом запуске Maven может потребоваться интернет для зависимостей. На машине автора тесты ранее выполнялись на JetBrains Runtime 25 с целевой версией Java 17: 9 тестов, 0 ошибок, 0 пропусков. Рецензенту следует указать собственное окружение и результаты своего запуска, либо прямо отметить, если запуск не выполнялся.

Дополнительная проверка Python из корня репозитория:

```powershell
python run_cases.py
python -m unittest discover
```
