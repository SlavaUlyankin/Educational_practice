# Java-модуль VR-арены

Модуль реализует логику бронирования и истории, контроля сеанса, выдачи и возврата комплектов. Данные и журналы хранятся в памяти. Оплата и база данных не реализованы. Сборка нацелена на Java 17; единственная библиотека приложения для тестов — JUnit 5.

## IntelliJ IDEA

1. Установите JDK 17, если он отсутствует. В PowerShell: `winget install EclipseAdoptium.Temurin.17.JDK`.
2. В IntelliJ IDEA выберите **File → Open** и откройте папку `java` этого репозитория. Дождитесь загрузки Maven-проекта и зависимостей. При первом запуске необходим доступ к Maven Central.
3. Откройте **File → Project Structure → Project** и выберите установленный JDK 17 в **SDK**. Уровень языка и целевая версия проекта задаются файлом `pom.xml`.
4. На панели Maven выполните **Lifecycle → test**. Альтернативно откройте `src/test/java/ru/mirea/vrarena/ArenaServicesTest.java` и запустите тесты зелёной стрелкой у класса.
5. Откройте `src/main/java/ru/mirea/vrarena/Demo.java` и нажмите зелёную стрелку у метода `main`. В окне Run появятся результаты бронирования, конфликта, переноса, работы сеанса, возврата и неявки.

Отдельная установка Maven не обязательна: IntelliJ IDEA использует встроенный Maven. Если используете терминал, установите Maven и добавьте его в PATH; `java -version` должен показывать JDK 17 или более новый JDK с поддержкой компиляции в Java 17.

## Командная строка

Из каталога `java`:

```powershell
mvn -q test
java '-Dfile.encoding=UTF-8' '-Dstdout.encoding=UTF-8' -cp target/classes ru.mirea.vrarena.Demo
```

`mvn test` компилирует основной код и тесты перед запуском тестов. Для повторяемых проверок сервисы принимают `java.time.Clock`; демо использует фиксированные моменты времени. Алгоритм проверки слота фильтрует брони и комплекты по площадке. Дополнительно по сравнению с Python-прототипом Java проверяет активность площадки и её вместимость.

На машине разработки тесты выполнены JDK JetBrains Runtime 25 с `--release 17`; байткод имеет версию 61 (Java 17). Самостоятельный запуск на установленном JDK 17 ещё не проверялся.
